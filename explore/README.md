# Explore

Activities for the ten solutions in this repo. Each one stands alone. Do them in any order, or read straight through: hints and answers are folded shut, and you open them when you want to.

| Activity | What it is |
|---|---|
| [Scavenger hunt](scavenger-hunt.md) | Eight things to find in the code. |
| [One function, ten ways](one-function-ten-ways.md) | `addTransaction` in all ten solutions, in four groups. |
| [Where the assignment was unclear](where-the-assignment-was-unclear.md) | Five decisions the assignment left open, and what the ten did with them. |
| [Pick the best](pick-the-best.md) | Six questions to ask of any codebase, and a best solution for five different needs. |
| [Validation, step by step](validation-step-by-step.md) | Seven versions of one check, from hand-written `if` statements to the Zod library. |
| [Break it](break-it) | A tool that makes up hundreds of inputs and looks for one that breaks a rule. Runs on four of the solutions. |
